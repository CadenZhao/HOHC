# HOHC — Human Organ Hormonal Communication

Interactive atlas of hormonal communication between human organs, linking
hormone classes, source organs, receptor organs and receptor types based on
GTEx v8 expression data.

- **Live site:** https://hohc.pages.dev/ (static web app, Cloudflare Pages)
- **Legacy URL:** https://omicsexplorer.shinyapps.io/HOHC/ (redirects to the
  live site; kept so the URL published in the paper keeps working)
- Previous Shiny implementation: archived at
  [HOHC-shiny-legacy](https://github.com/CadenZhao/HOHC-shiny-legacy)

## Repository layout

| Path | Contents |
|---|---|
| `site/` | The current website: static HTML/CSS/JS, interactive ECharts sankey. Deployed as-is to Cloudflare Pages |
| `site/data/hohc_data.json` | Web data bundle, generated by `scripts/export_web_data.R` |
| `data/GTEx_HR_combined.tsv.zip` | Raw per-subject GTEx expression table (unzip to regenerate the 156 MB TSV, which is gitignored) |
| `data/hormone_receptor_list.xlsx` | Hormone / hormone-receptor annotation table |
| `data/GTEx_HR_mean.rds` | Pre-aggregated mean TPM per (gene, organ, sex), from `scripts/preprocess_data.R` |
| `scripts/preprocess_data.R` | Builds `GTEx_HR_mean.rds` from the raw TSV |
| `scripts/verify_equivalence.R` | Proves the aggregation gives results identical to the raw data |
| `scripts/export_web_data.R` | Builds `site/data/hohc_data.json` |
| `app.R`, `sankey.R`, `www/` | Optimized legacy Shiny app (loads the aggregated RDS) |
| `app_original_backup.R` | The Shiny app exactly as published in 2024 |
| `redirect_app/` | Minimal Shiny app deployed at the legacy shinyapps.io URL; redirects to the live site |
| `manifest.json` | R package manifest from the original shinyapps.io deployment |

## Rebuilding the website from scratch

```bash
# 1. Regenerate the raw TSV (only needed to re-run the preprocessing)
unzip data/GTEx_HR_combined.tsv.zip -d data/

# 2. Rebuild the derived data (R with tidyverse, readxl, jsonlite)
Rscript scripts/preprocess_data.R
Rscript scripts/verify_equivalence.R   # should print ALL CHECKS PASSED
Rscript scripts/export_web_data.R

# 3. Preview locally
python3 -m http.server 7789 -d site
# open http://localhost:7789
```

Deploy: upload the contents of `site/` to any static host. The production
site is a Cloudflare Pages project (`hohc`); a new deployment is a zip of
`site/` uploaded via the Pages dashboard (Direct Upload). When changing
`site/css/*` or `site/js/*`, bump the `?v=` query strings in
`site/index.html` so returning visitors get the new assets.

## Keeping the legacy URL alive

shinyapps.io deletes free-tier apps that stay unused. A Cloudflare Worker
(`hohc-keepalive`) pings the legacy URL and the live site monthly. The
redirect app itself can be redeployed with:

```r
rsconnect::deployApp("redirect_app", appId = 13444974, account = "omicsexplorer")
```
